排兵布陣的底層邏輯

先決定「用誰贏」，再決定「怎麼撐到他贏」，最後才是站位。

組陣容

  • 骨架 = 1 個主 C ＋ 前排。主 C 決定 AD 或 AP 裝，前排存在的意義是幫主 C 買施法時間。常見結構是「主 C 羈絆 ＋ 1～2 個坦克羈絆」。
  • 羈絆門檻不是線性的。2→4 常是質變，所以第 9、10 格常拿去多開一個 2 層羈絆，而不是追高層（直羈絆 vs 橫向）。
  • 兩種節奏擇一：Reroll（5～7 級刷 1～3 費三星，前期強、上限有限）或快 8／快 9（存滿 50 金利息衝等級，拿 4、5 費二星，上限高）。
  • 魔力決定 C 位的出裝。魔力上限低（例如 0/30）的施法者靠回魔與增傷就能一直放技能；被動型棋子（沒有魔力條）主要吃攻速與坦度。
  • S19 新增「解鎖鏈」：94 隻裡有三十幾隻要先完成任務才會出現在商店。判斷能不能玩一套，先看解鎖條件做不做得到。

站位

  • 棋子先打最近的敵人：坦克放前排，主 C 放後排角落。
  • 對手有刺客就把 C 換邊或旁邊放坦克當誘餌；對手範圍傷害高就散開。
  • S19 有好幾個羈絆直接看站位：Choreographer（前兩排拿護盾、其他拿增傷）、Emo（Amumu 開場旁邊不能有隊友）、Manager（聚光燈格）、Beach Pop（樂器加強相鄰隊友）、Vladimir 解鎖（前兩排只能放指定數量）。
